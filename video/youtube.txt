TITLE
Vigil: Claude Code fixes a live outage in Mattermost, and only a person can ship it (built on Switch)

DESCRIPTION
Vigil runs a production incident across three linked Switch rooms. A sentinel agent takes command, Claude Code writes the fix in the team's Mattermost, another agent checks it with the real tests and a staging replay, and a release gate made of plain code refuses every agent. Only a person typing "approve" in chat can ship.

Everything in this film is real: INC-2046 on the live deployment on Nov 6, 2026. A bad release broke JPY checkouts with HTTP 500. Claude Code reproduced it, recognised the regression from an earlier incident and wrote a 12-line fix (commit 26c3213). Vigil's patcher passed it on 7 of 7 checks, an agent's own approval was refused (REJECTED_AGENT_SENDER), a person approved it in Mattermost, and all 5 canary probes passed. Alert to closed: 77 seconds. On the next incident (INC-2047) a teammate, Nzubechukwu, approved the release from their own Mattermost account.
